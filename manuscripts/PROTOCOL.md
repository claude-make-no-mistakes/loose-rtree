# Extension experiments

The three comparisons reuse the frozen input manifests, correctness criteria and optimized controls from the [second round](../twice/PROTOCOL.md). These are development cohorts. The new implementations also run against the preceding winners. All timings use one workstation and one BLAS thread. Inputs run in the archived order with a seeded shuffle of methods within each repeat, one warm-up and three measured repetitions. Run one timed study at a time.

## Spatial queries

Test whether routing a rectangle by its width and centre reduces the cost of rectangles crossing cell boundaries. Use six levels and the previous flat-leaf promotion capacity. Preserve both reinsertion settings, all 72 primary replays and all four scaling replays. Compare the loose directory, strict directory and original pruned R*-tree on identical traces. Check range IDs and nearest distances against the archived signatures, independent scan checks and structural checkpoints. Pair median phase times, sum across the three primary profiles within a county, and resample counties. Report the hotspot profile and build-inclusive results separately.

## Sparse systems

Move the eight mutable diagonal coordinates to the end of the supplied AMD order while preserving the order of the other coordinates. Test whether updating only the trailing Schur complement can eliminate the eight response solves and improve stability. Charge construction, the change of ordering, all twelve chronological requests, numerical checks and any fallback. Compare with the original checked Woodbury solver and the preceding adaptive solver on all 19 SPD matrices. A separate diagnostic may test a small-band or other structured factorization if the first candidate falls short. Record its rule before timing. Require independently recomputed backward error at most $10^{-11}$ for every measured result, and report the largest manufactured forward error. Report equal-weight matrix medians and paired bootstrap intervals, also charging shared AMD separately.

## Wheel delivery

Use the previously confirmed per-wheel recipe as the control. Test whether deriving valid SHA-256 fields in the wheel's RECORD from reconstructed archive members reduces delivered bytes. Retain the smaller byte-exact patch per project, accounting for the entire recipe. Require the old winner to reproduce, decode both candidates from the old wheel and patch alone, and re-encode the selected product. Sum bytes across all 16 projects and compare with both the original 888,127 bytes and the preceding 441,126 bytes. The selection tests size. Encoding time of the earlier timed trial is a separate result.

## Manuscripts

Write individual drafts for cubature, dynamic spatial indexing, repeated sparse SPD solves and wheel deltas. Trace numbers to checked journals. Distinguish the original held-out comparisons from subsequent development on reused cohorts and identify unresolved limitations in each paper.

As a separate work-count experiment for the cubature paper, coalesce the identical centre point shared by all pilot rays for deterministic pointwise callbacks. Compare the new mode with the frozen ray results on all 320 inputs and both tolerances. Record callback counts, truth-based success and false convergence. Report any changed outcomes. This experiment makes no wall-time claim.
